# Windows Server Home Lab

## Overview

This project documents my progress learning Windows Server administration and networking through a virtual home lab. I will record the configuration steps, explain my decisions, and include test results and troubleshooting notes.

## Current Status

Planning and documentation setup. The GitHub repository has been created; the virtual machines have not been installed yet.

## Planned Milestones

- Check my desktop's hardware and choose virtualization software.
- Install Windows Server in a virtual machine.
- Configure the server name and network settings.
- Create a shared folder and test read and edit permissions.
- Add Active Directory Domain Services and a Windows client virtual machine.
- Practice domain accounts, groups, and Group Policy.

## Documentation Approach

For each milestone, I will record the goal, important settings, verification results, and lessons learned. Screenshots and notes will use test accounts and sample data.

## Results

Configuration and test results will be added as each milestone is completed.
